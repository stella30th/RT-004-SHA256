\subsection{Gemini Results}
\label{subsec:gemini_results}
The archived Gemini P0 run had 86 passing suites among 94 task slots and eight failures. CE023 failed to compile because its supplied target source referred to \texttt{ClassroomManagementTest.Course} while the execution project defines \texttt{Classroom.Course}. A new P1 suite generated from corrected source passed four tests, but no successful rerun of the original P0 suite has been found. Excluding CE023 leaves 86 P0 passes and seven eligible failures among 93 valid pairs.

Five of those seven P1 suites passed (71.43\%). Their P0 discrepancies involved cipher behavior, expression parsing, suffix transformation, token counting, a missing JUnit import, and fixture-sensitive file processing. CE033 and CE037 remained unsuccessful: each P1 suite addressed an earlier cipher discrepancy yet retained a failing Vigenere assertion.

A separate Gemini round-2 archive contains seven historically failing tasks, three prompt conditions, and three recorded runs per condition (63 suites). Its single-task baseline A passed 17/21, checklist-only B passed 18/21, and checklist-plus-focus C passed 15/21. All 13 unsuccessful suites compiled and ran but had one assertion failure. These new prompts differ from the historical multi-task P0 context, so A is not an exact historical P0 replay. Final CE094 outcomes followed an infrastructure-only harness rerun. The per-run metadata in the committed archive does not independently verify the model version or interface, and no Gemini mutation results are reported.
