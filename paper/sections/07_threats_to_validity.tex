\section{Threats to Validity}
\label{sec:threats}
\textbf{Internal validity.} Historical P1 mixes an additional model call, a general checklist, and human-authored failure focus; no equal-budget historical P0 control isolates their effects. The round-2 ChatGPT records include two labeled replacement P0 outputs (CE085 run-01 and CE033 run-03), and two P0 run pairs have identical source hashes. These records are retained and disclosed rather than treated as verified independent generations. CE023 used different P0 and P1 target sources; its P1 PASS is excluded from the valid historical cohort.

\textbf{External validity.} Historical results cover 94 Java classes and two interface-labelled model configurations. The separate three-condition cohorts cover 11 ChatGPT and seven Gemini tasks selected after historical failure. Gemini's new single-task baseline differs from its historical multi-task context. Findings cannot be generalized to new task samples, model snapshots, or projects without replication.

\textbf{Construct validity.} JUnit PASS means compilation and execution with zero reported failures/errors against the current implementation. It does not verify specification correctness. PIT mutation score is a separate proxy for artificial fault sensitivity; no-coverage mutants count as not killed, and equivalent mutants or real defects were not independently assessed. P0 mutation results are conditional on 23 valid suites, while both checklist conditions have 33 valid suites.

\textbf{Conclusion validity and reproducibility.} The original 15/18 exact interval describes a small, failure-selected cohort and does not remove selection bias. Round-2 task--run cells repeat 11 ChatGPT or seven Gemini tasks, so suite observations are not independent task samples; no confirmatory model or condition test is claimed. The repository contains unpacked raw evidence for 99 ChatGPT suites, 89 eligible PIT runs, and 63 Gemini suites. Hào's five named ZIP packages are absent, while Khoa's Official\_Run ZIP is present. Generation-session provenance and some settings remain incomplete; all 63 committed Gemini metadata files leave model-version and interface fields empty despite the report's self-reported label. The Gemini protocol is still marked draft. Historical, round-2, and provisional 188-pair sensitivity counts remain separate.
