# Week 6 Evidence

This folder contains the Week 6 evidence package based on five full papers:

1. Evaluating and Improving ChatGPT for Unit Test Generation
2. Using Large Language Models to Generate JUnit Tests: An Empirical Study
3. YATE: The Role of Test Repair in LLM-Based Unit Test Generation
4. Context Matters: Improving the Practical Reliability of LLM-Based Unit Test Generation
5. ASTER: Natural and Multi-language Unit Test Generation with LLMs

`week6-core5-evidence.xlsx` contains the detailed evidence matrix, RQ mapping, failure taxonomy, and YATE extraction.

`week6-final-result-with-prisma.xlsx` summarizes the Week 6 state and the completed Google Scholar source-level PRISMA.

Note: Google Scholar is source-level complete. IEEE is not yet complete because IEEE-A02 to IEEE-A04 are still pending.
