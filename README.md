**Topic:** RT-SWT302-004

## Research Topic
**Task Categories Where ChatGPT- and Gemini-Generated JUnit Tests Fail to Run**

## Research Question
On a frozen subset of 30 HumanEval problems, using the same structured prompt and one compiler-feedback repair round, which task categories cause JUnit test suites generated by ChatGPT or Gemini to have lower compile-and-execute success rates than a human-written baseline?

## Research Workflow
1. Freeze RQ, PICO, dataset version, prompt version, environment and taxonomy.
2. Search and screen literature using the same protocol.
3. Create and freeze the human baseline **before** inspecting AI outputs.
4. Pilot on 5–10 problems.
5. Freeze approved amendments.
6. Run the full 30-problem experiment.
7. Compute overall/per-category metrics and paired statistical tests.
8. Write paper and presentation.

## Non-negotiable Experiment Rules
- Không sửa tay output JUnit của AI.
- Không retry đến khi pass.
- Tối đa **1** compiler-feedback repair round.
- Không thay prompt theo từng problem.
- Empty/invalid output vẫn phải log.
- Human baseline phải freeze trước khi xem output AI.
- Không đổi metric/threshold sau khi đã xem full result.
