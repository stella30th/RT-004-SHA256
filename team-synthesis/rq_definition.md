# RQ Definition

## Topic
Task Categories Where ChatGPT- and Gemini-Generated JUnit Tests Fail to Run

## Research Question
On a frozen subset of 30 HumanEval problems, using the same structured prompt and one compiler-feedback repair round, which task categories cause JUnit test suites generated by ChatGPT or Gemini to have lower compile-and-execute success rates than a human-written baseline?

## Population
30 frozen HumanEval problems.

## Intervention
JUnit test generation using:
- ChatGPT
- Gemini

Both models receive the same task information and the same
structured prompt.

## Comparison
Human-written JUnit test suites created before inspecting
AI-generated tests.

## Primary Outcome
A generated test suite is successful when:

1. it compiles successfully; and
2. it can be executed by the JUnit test runner.

success = compile_success AND execution_success

## Repair Policy
If the first AI-generated test fails compilation, the compiler
error is returned to the same model.

Only one repair round is allowed.

No manual modification of AI-generated tests is permitted.

## Analysis
Results are compared:
- overall;
- by task category;
- Human vs ChatGPT;
- Human vs Gemini;
- ChatGPT vs Gemini.

## PICO
| Element | Definition |
|---|---|
| Population | Frozen subset of 30 HumanEval problems |
| Intervention | ChatGPT- and Gemini-generated JUnit tests using one frozen structured prompt and one repair round |
| Comparison | Human-written JUnit baseline created before AI output is inspected |
| Outcome | Compile success, execution success, combined compile+execute success |
| Study design | Paired comparison on the same problems, analyzed overall and by task category |

## Draft Hypotheses
### Global
H0: There is no difference in compile-and-execute success among Human, ChatGPT and Gemini.

H1: At least one condition differs.

### Planned follow-up

- ChatGPT vs Gemini
